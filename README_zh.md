# ⚛️ 交互式元素周期表 (Interactive Periodic Table)

一个现代、优雅且功能完备的高性能**交互式元素周期表** Web 应用程序。基于 **React 19**、**TypeScript**、**Tailwind CSS**、**Recharts** 与 **Motion (Framer Motion)** 构建。

支持 5 种语言无缝切换：**简体中文**、**English**、**繁體中文**、**日本語** 与 **한국어**。

🌐 **在线演示地址 (Live Demo)**：[https://chunshilaioqf.github.io/periodic_table/](https://chunshilaioqf.github.io/periodic_table/)

👉 [English Documentation (README in English)](./README.md)

---

## ✨ 核心功能亮点

### 1. 🔬 118 种元素全量数据库与中心预览 (Quick View)
- 完整收录并精准排布全部 118 种化学元素（涵盖主表以及镧系、锕系）。
- **中心空隙速览**：当鼠标悬停在周期表任一元素单元格时，主表空白区域将以流畅弹簧动画即时展示该元素的序号、化学符号、中文名称、相对原子质量与分类标签。
- 包含每个元素的核外电子构型、物理常数、科学发现历史故事与详细百科描述。

### 2. 📈 周期性物理与化学性质趋势图表 (基于 Recharts)
- 专为化学学习与科学研究打造的宏观递变规律分析模块。
- **多维度视角切换**：
  - **同周期递变 (Across Period)**：展示第 1 ~ 7 周期内从左至右的变化趋势。
  - **同主族递变 (Across Group)**：展示第 1 ~ 18 族自上而下的渐变特征。
- **支持的核心物理/化学性质**：
  - **原子半径 (Atomic Radius)** (单位：pm)
  - **鲍林电负性 (Pauling Electronegativity)**
  - **熔点 (Melting Point)** (单位：°C)
  - **沸点 (Boiling Point)** (单位：°C)
  - **第一电离能 (First Ionization Energy)** (单位：kJ/mol)
  - **单质密度 (Density)** (单位：g/cm³)
- **图表交互与科学原理解析**：图表中对当前选中元素以光晕脉冲点突出标记；支持直接点击图表数据点跳转至目标元素；并动态提供该属性在周期律下的物理机理解读与极值统计。

### 3. 🪐 玻尔原子轨道模型 (3D 动态模拟)
- 根据真实核外电子排布（K、L、M、N、O、P、Q 能层：$2, 8, 18, 32\dots$）动态渲染电子绕核旋转的 SVG 玻尔模型。
- 具备不同轨道周期的旋转速率、电子光晕渲染与电子层数即时汇总。

### 4. ⚖️ 双元素并排对比模式 (Side-by-Side Comparison)
- 支持选取一个基准元素后，在周期表中点选第二个元素，并排对比两者的原子量、元素所属分类、各能层电子分布差异。

### 5. 🧠 化学符号趣味测验 (Quiz Mode)
- 内置元素符号记忆挑战，随机出题并自动生成干扰选项。
- 包含得分累计、正确答案彩色纸屑礼花特效（Confetti）以及基于 Web Audio API 合成器的轻量交互音效。

### 6. 🌐 深度多语言本地化 (i18n)
- 100% 完整覆盖 5 种主流语言：
  - 简体中文 (`zh-CN`)
  - 英语 (`en`)
  - 繁体中文 (`zh-TW`)
  - 日语 (`ja`)
  - 韩语 (`ko`)
- 不仅包含元素名称，所有分类标签（碱金属、碱土金属、过渡金属、稀有气体等）、物理量指标、图表文案、弹窗指南与操作按钮均已实现完全本地化，无漏译英文。

### 7. 🎨 个性化定制与精致 UX 细节
- **暗黑 / 明亮主题**：一键切换，色彩对比均符合无障碍高阅读标准。
- **主题强调色选择**：提供 7 款精心搭配的强调色调（电光蓝、珊瑚红、翡翠绿、琥珀黄、紫罗兰、樱花粉、青色）。
- **彩蛋特效**：点击金元素（**Au**）时将触发专属的金色礼花庆祝。
- **便捷快捷键**：按下键盘 `/` 键即可一键聚焦搜索框；按 `Esc` 键快速关闭当前弹窗。
- **数据导出**：支持一键将完整的 118 种元素结构化数据导出为 JSON 文件。
- **滚动进度与一键置顶**：顶部提供细致的阅读进度条，并在页面滚动时提供平滑置顶浮动按钮。

## 🚀 本地开发与部署运行

### 环境准备
- Node.js（推荐 v18.0 或更高版本）
- npm、pnpm 或 bun 均可

### 操作步骤

1. **克隆项目到本地**：
   ```bash
   git clone <仓库地址>
   cd <项目目录>
   ```

2. **安装项目依赖**：
   ```bash
   npm install
   ```

3. **启动本地开发服务器**：
   ```bash
   npm run dev
   ```
   启动后在浏览器中访问 `http://localhost:3000`。

4. **代码类型与语法检查**：
   ```bash
   npm run lint
   ```

5. **执行生产构建**：
   ```bash
   npm run build
   ```
   构建产物将输出至 `dist/` 目录。
